# Kockaya Objektrechner

Immobilien-Kalkulator von Kockaya Immobilien. Läuft komplett im Browser, auch offline.

- Prozente (Notar, Makler, GrESt, EK, Zins, Tilgung, AfA, Bewirtschaftung) frei einstellbar
- Live-Berechnung von Anschaffungskosten, Rate, Ertrag, Cashflow, Rendite, Restschuld
- PDF-Export per Knopfdruck
- Optimiert für Handy und Desktop

Nutzung: `index.html` im Browser öffnen oder über GitHub Pages aufrufen.

Unverbindliche Kalkulation, keine Steuer- oder Finanzberatung.
